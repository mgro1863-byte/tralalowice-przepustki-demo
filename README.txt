Szkoła im. Janka Muzykanta w Tralalowicach – wersja demonstracyjna PWA

1. Rozpakuj ZIP.
2. Wgraj zawartość (index.html, manifest.webmanifest, sw.js i ikony) do publicznego folderu hostingu HTTPS, np. GitHub Pages.
3. Otwórz adres strony na telefonie w Chrome; menu ⋮ → Dodaj do ekranu głównego / Zainstaluj aplikację.
4. Zezwól na użycie kamery i przetestuj QR.

UWAGA: To demonstrator zawierający lokalne przykładowe rekordy. Nie jest bezpiecznym systemem kontroli dostępu i nie wolno publikować w nim rzeczywistych danych uczniów/rodziców.
Skrypty qrcodejs, html5-qrcode i xlsx są pobierane z CDN i wymagają połączenia internetowego.
Nie wrzucaj całego projektu Android Studio na hosting, tylko pliki z tego ZIP.
